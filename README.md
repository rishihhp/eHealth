# 💙 eHealth

**An AI-powered health assistant platform designed to support patients through accessible tools, voice interaction, and motion-based input.**

---

## 🌟 Overview

**eHealth** is a multi-modal digital health assistant that blends **AI, deep learning, voice recognition, and computer vision** to create an accessible support system for individuals needing on-the-go medical help. It was built as both a **technical challenge and a life mission**—this project has been implemented in public care facilities, earned national recognition, and continues to evolve.

> 🏆 **Rise Finalist**, **Congressional App Challenge Winner**, **QBH Hackathon Winner**  
> 💬 “This app got me into Stanford.”  
> 🏥 Successfully piloted at public care facilities—**staff loved it**  
> 🌱 A lifelong project built with purpose and heart

---

## 🧠 Key Features

### 1. 💡 Health Assistant (Core)
- Natural language-based health inquiry system
- Uses **NLTK**, **neural networks**, and **intents.json** for intelligent responses
- Trained using machine learning to match user queries with appropriate medical info

### 2. 🎙️ Voice Assistant
- Built with **DeepSpeech** for voice-to-text input
- Converts speech into actionable queries for the health assistant
- Designed to replace reliance on external assistants like Siri or Alexa

### 3. ⌨️ Virtual Keyboard
- Works using webcam and **MediaPipe** + **OpenCV**
- Typing simulated by touching **index and middle fingers** together
- Fully functional **outside the application window**

### 4. 🖱️ Virtual Mouse
- Cursor follows your **pointer finger**
- Click simulated by extending your **thumb**
- Enhances accessibility for users with limited device input options

---

## 🔐 Facial Recognition Login

- Uses a **machine learning model** and **face encodings** stored in `Encodings.p`
- Login attempts and activity securely tracked using **Google Firebase**
